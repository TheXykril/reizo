# Contributing

Thanks for helping. The project is private and pre-alpha for now; these rules apply to humans and
coding agents alike.

1. Read [AGENTS.md](AGENTS.md) (rules) and [docs/AGENT_PROTOCOL.md](docs/AGENT_PROTOCOL.md)
   (session workflow).
2. Pick or open an issue; comment that you are taking it.
3. Branch from `main`: `feat/...`, `fix/...`, `docs/...`.
4. Write tests with the change. `./gradlew build` must pass; run gametests for `fabric/` changes.
5. Use Conventional Commits. Open a pull request using the template.
6. Never contribute code copied or ported from Flashback, Hindsight, Lunar Client or Replay Mod
   ([ADR 0005](docs/DECISIONS/0005-clean-room-policy.md)).

By contributing you agree your contribution is licensed under GPL-3.0-or-later.
